# IPL Analysis Dashboard – README

## Overview

The **IPL Analysis Dashboard** is an interactive and dynamic Power BI dashboard designed to analyze Indian Premier League (IPL) performance statistics for the **2023 season**.

The dashboard provides insights into:

* Team performance
* Batting statistics
* Bowling statistics
* Tournament achievements
* Player awards
* Match-winning trends

Using dynamic filters and visualizations, users can explore detailed IPL analytics in a visually engaging way.

---

## Features

### Dynamic Year Selection

* Users can select a season/year from the dropdown filter.
* All charts, KPIs, and statistics update automatically based on the selected year.

### Tournament Insights

Displays key tournament highlights such as:

* Tournament Winner
* Orange Cap Holder
* Purple Cap Holder
* Most Player of the Match Awards

### Batting Analysis

Provides batting-related statistics including:

* Total Runs
* Total 4’s
* Total 6’s
* Strike Rate

Includes:

* Dynamic batsman selector
* Top 5 batsmen comparison chart

### Bowling Analysis

Provides bowling-related statistics including:

* Total Wickets
* Economy Rate
* Strike Rate

Includes:

* Dynamic bowler selector
* Top 5 bowlers comparison chart

### Team Performance Analysis

Visualizes:

* Top winning teams
* Match result distribution
* Team-wise wins and wickets

### Match Result Insights

* Toss decision impact visualization
* Field vs Bat first winning percentage analysis

## Dashboard Components

| Section         | Description                                     |

## Interactivity

This dashboard is fully dynamic:

* Selecting a batsman updates batting KPIs.
* Selecting a bowler updates bowling KPIs.
* Changing the year refreshes the entire dashboard.
* Charts interact with one another for deeper analysis.
